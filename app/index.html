黄金 COT 看板 iOS App

原生 SwiftUI · 与网页版同源同口径 · 数据每小时自动更新

功能一览

  • 持仓看板：最新报告卡片、周/月/季/年切换、管理基金净持仓 vs 金价（双轴）、五类交易者对比、多空分项、总持仓、金价 vs 美元指数、黄金期权 PCR（沪金 + 美国 GLD）
  • 技术分析：日K/周K/月K、K线+布林带+斐波那契回撤位、MA5-250、金价 vs 开采成本 AISC、MACD 金叉/死叉标注

方式一：一键"添加到主屏幕"（无需安装，推荐）

网页版已完美适配手机，用 Safari 打开看板后：

  1. 点底部分享按钮 ⎋
  2. 选"添加到主屏幕"
  3. 桌面上即出现独立图标，全屏运行如原生 App

零成本、自动更新、不占存储，体验与 App 基本一致。

方式二：源码构建原生 App（需 Mac + Xcode）

下载源码包，三步构建：

brew install xcodegen   # 只需一次
cd app && xcodegen
open GoldCotTracker.xcodeproj   # ⌘R 运行
  1. 下载：下载源码包 (GoldCotTracker-app.zip)
  2. 解压后进入 app/ 目录，执行上面的命令
  3. 模拟器直接运行；真机用免费 Apple ID 登录 Xcode，勾选 Automatically manage signing 即可安装到自己手机（7 天重签）

源码已包含完整工程配置（project.yml），详见包内 README.md。 分发给他人安装需要 Apple Developer 付费账号（$99/年）签名。

数据源

App 与本网页读取同一份数据（GitHub Actions 每小时自动更新）：

  • data/cot_data.json — COT 持仓 / 金价 / 美元指数 / 期权 PCR
  • data/ta_data.js — 技术分析行情（OHLC / 开采成本）
